### 💀 F Arcade.dev Arcade (agent tool-calling and auth platform)

Agents call the Arcade Engine with a static project API key that Arcade calls an administrator credential, with no public key-management API, no documented scoping or last-used data, and no GitHub secret-scanning partnership. Outbound, Arcade-managed OAuth apps (Google, Microsoft and others) need no customer secret, but GitHub, Slack, Salesforce, Okta and API-key toolkits do.

- **Inbound F:** Static project API key sent as a Bearer token to the Engine API; created in the dashboard or printed by `arcade login`. No workload federation or token exchange is documented.
- **Outbound B:** Per-user OAuth through Arcade-managed default OAuth apps (Google, Microsoft, Atlassian, HubSpot, ServiceNow, Zendesk and others) and Dynamic Client Registration for the AWS MCP Server need no customer secret; GitHub, Slack and Salesforce need a customer-owned OAuth app and client secret; Okta group checks and API-key toolkits (Datadog, Postgres) need static keys.

### 💀 F Material Security Material platform (API v1)

Material's API accepts only a static per-account token in an x-material-client-secret header, with no documented expiry, last-used timestamp, token API or leak revocation. Material reaches Google Workspace through domain-wide delegation to its own app, but Okta, Duo, OneLogin, Slack and SIEM connectors all want a pasted token or secret.

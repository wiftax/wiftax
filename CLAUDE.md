# wif.tax

Read `RUBRIC.md` before grading and `README.md` before writing a card. `npm run check` must pass.

- Grade new cards the same way as the existing ones. Before calling a grade, find two existing cards
  with the same setup and match them. If they disagree, raise it in the PR instead of picking one.
- Card text is for readers. Notes on fetching, rendering or pages you could not read go in the PR
  description.
- Keep a PR to about 10 new cards so a person can review every grade.
